# 🔐 Termux-Lock

Termux-এ ঢোকার সময় পাসওয়ার্ড চাইবে এবং পাসওয়ার্ড ভুলে গেলে রিকভারি কোড দিয়ে অ্যাক্সেস দেওয়ার একটি নিরাপদ টুল।

## ✨ ফিচার

- SHA-256 হ্যাশিং দিয়ে পাসওয়ার্ড সংরক্ষণ
- গোপন ইমার্জেন্সি রিকভারি কোড
- Ctrl+C / Ctrl+Z ব্লক
- হালকা ও দ্রুত
- সম্পূর্ণ ওপেন সোর্স
